# SITE CONTEXT

This file is the single source of truth for the UI Tenets & Traps **website structure and
naming** (navigation, page names, where each tool lives). The chat injects it into its system
prompt and is instructed to use these names and locations — they override any older names that
may appear elsewhere in the knowledge base.

Keep this file up to date whenever the website's navigation or page names change. (It is kept
separate from the framework knowledge on purpose, so site changes never require editing the KB.)

- **Site:** UI Tenets & Traps — https://uitraps.com
- **Trap Analyser** — the structured analysis tool: upload screenshots, a Figma frame, or a URL
  and get a structured report. Found under the **"AI Tools"** menu in the main navigation.
- **Ask me anything** — this chat assistant. Also under the **"AI Tools"** menu.
